# TradeMe 0.3.0

- Adds built-in update checking, download progress, and an explicit restart-to-install flow in Settings.
- Installed Windows builds check published stable releases after startup and show an update banner.
- Creates a saved-library backup before installation; a backup failure blocks restart.
- Keeps local notes and research-chat data in their existing location.
- Includes the research question/reply workspace from version 0.2.0.

Install this Setup executable manually once. Future published updates can be downloaded inside the installed app. An extracted ZIP does not enable the installer-based update flow.

This is an unsigned early release. The complete Windows upgrade cycle has not yet been validated. Save your drafts and export a backup before upgrading. No AI, market/account connection, or trading functionality is enabled. PDF import is still pending.
